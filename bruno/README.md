# NTI E-Commerce API - Bruno Collection

مجموعة توثيق واختبار الـ API لمشروع متجر NTI الإلكتروني باستخدام أداة **Bruno**.

## 🚀 كيفية استخدام الـ Collection في Bruno

1. قم بفتح تطبيق **Bruno**.
2. اضغط على **Open Collection**.
3. اختر مجلد `nti-be/bruno`.
4. اختر البيئة **Local** من الزاوية العلوية اليمنى (تحدد `baseUrl` تلقائياً على `http://localhost:7000`).

---

## 🔑 المصادقة والـ Token التلقائي (Automation)

- عند تشغيل طلب **Login** (`01. Auth/Login`), يتم استخراج الـ `token` وحفظه تلقائياً في متغير البيئة `{{token}}`.
- الطلبات المحمية ترسل الـ Token في الـ Header باسم `x` كما يتطلب السيرفر:
  ```http
  x: {{token}}
  ```
- عند إنشاء تصنيف (Category) أو ماركة (Brand) أو منتج (Product)، يتم حفظ الـ IDs تلقائياً (`{{categoryId}}`, `{{brandId}}`, `{{productId}}`, إلخ) لتسهيل تجربة باقي الطلبات.

## 📁 أقسام الـ Endpoints في المجموعة

| القسم | الوصف | عدد الـ Requests |
| :--- | :--- | :--- |
| **00. Health** | فحص حالة تشغيل السيرفر | 1 |
| **01. Auth** | تسجيل حساب جديد وتسجيل الدخول | 2 |
| **02. User** | إدارة الملف الشخصي، تحديث البيانات، ورفع الصورة الشخصية | 3 |
| **03. Category** | استعراض، إضافة، تعديل، وحذف التصنيفات (مع رفع الصور) | 5 |
| **04. Subcategory** | استعراض، إضافة، تعديل، وحذف التصنيفات الفرعية | 5 |
| **05. Brand** | استعراض، إضافة، تعديل، وحذف الماركات والعلامات التجارية | 5 |
| **06. Product** | استعراض، إضافة (مع صورة)، تحديث، وحذف المنتجات | 4 |
| **07. Cart** | عرض السلة، إضافة منتج، تعديل الكمية، حذف منتج، وتفريغ السلة | 5 |
| **08. Order** | إنشاء الطلب، طلباتي، تفاصيل الطلب، إلغاء الطلب، وتحديث الحالة | 6 |
| **09. Review** | إضافة تقييم، استعراض تقييمات منتج، تعديل تقييم، وحذفه | 4 |

**الإجمالي: 40 نقطة نهاية (Endpoints) موثقة ومجهزة للاختبار الفوري.**
